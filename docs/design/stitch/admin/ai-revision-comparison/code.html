Section 3.2

Task Orchestration & Microtask Resolution

JavaScript evaluates synchronous scripts top-to-bottom within the active execution thread. When asynchronous triggers execute, their respective callbacks are deferred into queues until the call stack becomes void.

remove_circle Imprecise Explanation (Marked for Revision) Vague Timing

Asynchronous code registered with setTimeout or Promise executes soon after the main script clears. While Promises are processed relatively swiftly, developers usually perceive both queues as yielding identical deferral traits when setTimeout delay is set to 0.

setTimeout(() => {
  console.log('Timeout handler');
}, 0);

Promise.resolve().then(() => {
  console.log('Promise resolved');
});

console.log('Script end');

Section 3.2 (Enhanced)

Task Orchestration & Microtask Resolution

JavaScript evaluates synchronous scripts top-to-bottom within the single execution call stack. Microtask checkpoints guarantee deterministic, immediate drainage of microtasks before any subsequent macrotask is unqueued.

add_circle Enhanced Technical Precision (Added per directive) Strict Hierarchy

Microtasks registered via Promise.prototype.then() or queueMicrotask() are inserted into the dedicated Microtask Queue. Crucially, the engine will exhaust the entire microtask buffer completely before yielding back to the event loop turn to retrieve any macrotask (such as setTimeout(fn, 0)).

Modern API Demonstrator

ECMAScript 2024 
console.log('1. Script start');

// Macrotask queue insertion
setTimeout(() => {
  console.log('5. setTimeout (Macrotask)');
}, 0);

// Microtask queue insertions
Promise.resolve().then(() => {
  console.log('3. Promise.then (Microtask #1)');
});

queueMicrotask(() => {
  console.log('4. queueMicrotask (Microtask #2)');
});

console.log('2. Script end');
// Output: 1 -> 2 -> 3 -> 4 -> 5
