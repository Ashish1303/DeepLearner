Understanding Microtasks vs Macrotasks in the V8 Event Loop

In Node.js and modern browser runtimes, not all asynchronous actions are equal. The order of execution between resolved Promises and timer callbacks reveals how the engine prioritizes memory queues to prevent UI frame stutter.

lightbulb Core Invariant: Call Stack Starvation

The Microtask Queue is drained completely after every synchronous turn and before the host renders a new UI frame or yields to the next Task (Macrotask). Continual microtask recursion will starve the macrotask queue indefinitely.

Execution Sequence Rules

1 Stack Exhaustion Run every synchronous operation until the stack is completely empty.
2 Microtask Flush Process each microtask sequentially, including newly queued microtasks.
3 Single Macrotask Execute exactly one pending task from the macrotask queue, then cycle.
